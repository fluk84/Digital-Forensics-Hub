# Quantum Super Cyber Intelligence & Digital Forensics Hub (ศูนย์ข่าวกรองควอนตัมและนิติวิทยาศาสตร์ไซเบอร์ขั้นสูง)

A professional, enterprise-grade digital forensics investigation and quantum cyber intelligence command center web application. Built for cyber defense forensics analysts, incident responders, and security operations centers (SOC).

---

## 🚀 Key Features & Capabilities

### 1. Digital Forensics Case & Evidence Management (Evidence Locker)
- **Case Dossier & Overview**: Manage active cases, track case numbers, examiner details, and view high-level statistical summaries.
- **Evidence Locker with Recharts**: Visualizes the distribution of evidence file types (Disk Images, Memory Dumps, PCAP Captures, Event Logs, Triage Archives) using interactive Recharts bar charts and donut charts.
- **Chain of Custody (CoC)**: Cryptographic audit trails tracking evidence custody transfers, digital signatures, and integrity verification (SHA-256 / MD5 hash validation).
- **Artifact Analysis**: Deep-dive into Windows EVTX event logs, memory process dumps, network PCAP captures, MFT/Prefetch records, and registry persistence artifacts with severity indicators and MITRE ATT&CK mapping.

### 2. Quantum Super Cyber Intelligence Hub (ศูนย์ข่าวกรองควอนตัม)
- **Secure Gateway Lock Screen**: Enterprise-grade lock screen with TOP_SECRET clearance level, passcode authentication, and post-quantum cryptography protocol indicators (ML-KEM / ML-DSA NIST FIPS 203).
- **AI Command Center**: Multi-modal Gemini integration (Fast, Deep Thinking, Search grounding modes) for automated threat triage and tactical log analysis.
- **Real-Time Telemetry & Metric Charts**: Live streaming system metrics (CPU core load, memory allocation, network ingress bandwidth, quantum stability percentage).
- **Interactive 64-Node Neural Mesh**: Node status matrix with live health monitoring, anomaly alerts, node isolation, and parity matrix resets.
- **3D Threat Map & Satellite Uplink**: Global threat vector mapping and satellite communications relay telemetry.
- **Neural Voice Link**: Tactical voice interface supporting Speech Recognition (STT), Speech Synthesis (TTS) audio feedback, mute controls, and responsive audio visualizers.
- **Quantum Encryption Diagnostics**: Post-quantum cryptography readiness assessment, lattice-based encryption key exchange simulation, and mitigation tools.

### 3. Investigation & Reporting Tools
- **MITRE ATT&CK Matrix**: Tactic and technique mapping for threat actor attribution and attack lifecycle tracing.
- **AI Copilot & Report Generator**: Automated executive summary generation, root cause hypothesis formation, and one-click export of quantum telemetry snapshots into forensic case artifacts.
- **Export & Backup**: CSV/JSON export capabilities and secure chain of custody reports.

---

## 🛠️ Technology Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React, Recharts, D3-ready components.
- **Backend**: Node.js, Express proxy routes (`/api/quantum/*`, `/api/ai/*`).
- **Build Tool**: Vite.

---

## 🚦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Run Development Server**:
   ```bash
   npm run dev
   ```
3. **Build for Production**:
   ```bash
   npm run build
   ```
